HTA LAB · Logins

Everything on this page runs in your browser. Nothing you type here is sent anywhere. Passwords are never stored; each login only holds the site key, locked with that person's password.

1 · Site key

The site key encrypts the whole website. Create it once, then save it as a GitHub secret. Keep a copy somewhere safe, such as a password manager: you need it to add or remove people.

  1. On GitHub, open hta-lab/hta-lab.github.io → Settings → Secrets and variables → Actions.
  2. Click New repository secret. Name: SITE_KEY. Value: paste the key. Then click Add secret.
  3. Also save the key in your password manager.

2 · People who can sign in

At least 8 characters; longer is safer. To change someone's password, remove them and add them again. Someone who is removed stays signed in on his devices until you create a new site key and add everyone again.

3 · Publish the logins

This file contains only the locked site key for each person. It is safe to publish, but useless without the passwords. Send it to Claude, or upload it to the repository as access/users.json. The site locks itself on the next update.
